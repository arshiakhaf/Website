# ❓ سوالات متداول

## ۱) چرا سایت «کاملاً آفلاین» است؟
تمام اجزای سایت (وردپرس ۷.۱، ووکامرس، قالب، افزونه‌ها، فونت وزیرمتن و تصاویر) در همین مخزن هستند.
وقتی سایت در حالت آفلاین اجرا می‌شود (`ARIAN_OFFLINE`)، هیچ درخواستی به اینترنت نمی‌فرستد و حتی
زمان‌بندهای به‌روزرسانی ووکامرس هم معطل نمی‌شوند. فقط اولین `docker compose up` برای کش کردن تصاویر
Docker به اینترنت نیاز دارد.

## ۲) آیا می‌توانم سایت را روی هاست واقعی (cPanel/سرور) ببرم؟
بله. ساختار استاندارد وردپرس است:
- محتوای پوشه `wordpress/` را به `public_html` منتقل کنید.
- `wp-config.php` را با اطلاعات دیتابیس هاست بسازید.
- از `bin/seed.php` برای داده نمونه استفاده کنید یا از پیشخوان، دکمه «ابزار دمو» را بزنید.
- `wq` اطلاعات دیتابیس هاست را در `wp-config.php` جایگزین کنید.

## ۳) درگاه «آزمایشی» چیست و چگونه درگاه واقعی نصب کنم؟
درگاه آزمایشی (`arian-pay`) شبیه‌ساز بانک است تا بدون اینترنت و بدون حساب بانکی، کل سناریوی خرید را
تست کنید. برای درگاه واقعی:
1. افزونه درگاه (زرین‌پال، زیبال، سپ...) را از مخزن وردپرس نصب کنید.
2. ووکامرس → تنظیمات → پرداخت‌ها → درگاه جدید را فعال و کلید API را وارد کنید.
3. درگاه آزمایشی را غیرفعال کنید.

## ۴) نحوه تغییر زبان پیشخوان به فارسی
در سایت آنلاین: **تنظیمات → عمومی → زبان سایت → فارسی** (فایل زبان `fa_IR` از wordpress.org دانلود می‌شود).
در حالت کاملاً آفلاین، پیشخوان انگلیسی است ولی کل ظاهر و متن‌های فروشگاه فارسی است.

## ۵) دیتابیس کجاست؟
داخل حجم `dbdata` داکر. با `docker compose down -v` حذف می‌شود. پشتیبان: `bash bin/cli.sh backup`.

## ۶) چرا قیمت‌ها «تومان» بدون اعشار است؟
تنظیم پیش‌فرض پروژه است (ووکامرس → تنظیمات → عمومی → واحد پول).
برای ریال: `woocommerce_currency` را به `IRR` و نماد را در فیلتر قالب تغییر دهید.

## ۷) اشتباهی حجم/قیمت محصول را تغییر دادم؛ دمو را برگردانم؟
`bash bin/cli.sh provision` داده‌های نمونه را **بازسازی** می‌کند (محصولات قبلی با همان SKU نادیده گرفته می‌شوند).
برای شروع کاملاً تمیز: `bash bin/reset.sh`.

## ۸) سایت را روی لپ‌تاپ/سیستم دیگر می‌برم؟
کل پوشه پروژه + Docker را همراه داشته باشید؛ کافی است `docker compose up -d --build` بزنید.
(در سیستم جدید، اولین‌بار به اینترنت نیاز است.)

## ۹) آیا ووکامرس نسخه قدیمی است؟
پروژه با ووکامرس ۹.۴ (باندل آفلاین) کار می‌کند. برای آخرین نسخه:
`bash bin/fetch-woocommerce.sh && docker compose up -d --build`

## ۱۰) پیام‌های تماس کجا ذخیره می‌شوند؟
پیشخوان → «پیام‌های تماس». (فرم از صفحه `/contact/` ارسال می‌شود.)
