# 📘 راهنمای کامل اجرا، تست و شخصی‌سازی (آفلاین)

این راهنما همه‌چیز را گام‌به‌گام توضیح می‌دهد: از نصب Docker تا تست کامل یک خرید و مدیریت فروشگاه.

---

## ۰) پیش‌نیازها

| نیازمندی | نسخه | توضیح |
|---|---|---|
| Docker Desktop / Docker Engine | 20+ | شامل `docker compose` (نسخه ۲) |
| مرورگر | جدید | کروم/فایرفاکس/اج |
| اینترنت | فقط بار اول | برای کش کردن تصاویر Docker (بعداً آفلاین هم کار می‌کند) |

بررسی نصب:

```bash
docker --version      # باید خروجی بدهد
docker compose version
```

> در لینوکس: اگر از `www-data` یا پورت‌های ۸۰۸۰/۸۰ مشکل داشتید، `WEB_PORT` را در `.env` تغییر دهید.

---

## ۱) اجرای سایت

```bash
cd Website          # پوشه پروژه
cp .env.example .env
docker compose up -d --build
```

چیزی که اتفاق می‌افتد (همه خودکار):

1. **mariadb:10.11** بالا می‌آید (دیتابیس `arian` با یونیکد utf8mb4).
2. تصویر **PHP 8.2 + Apache** ساخته می‌شود (با gd, intl, zip, mbstring, mysqli).
3. `entrypoint.sh` منتظر دیتابیس می‌ماند، `wp-config.php` را با کلیدهای امنیتی جدید می‌سازد.
4. **فاز ۱ (`bin/provision.php`)**: نصب وردپرس ۷.۱، فعال‌سازی قالب `arian-shop` و افزونه‌های `arian-core`، `arian-pay`، `woocommerce`؛ تنظیمات (تومان، ایران، راست‌چین)، ساخت صفحات (خانه، فروشگاه، سبد، تسویه، حساب، تماس، پیگیری) و پیوندهای یکتا.
5. **فاز ۲ (`bin/seed.php`)**: ساخت ۶ دسته‌بندی، ۱۶ محصول با تصویر (۲ محصول با متغیر)، برند، نظرات، کوپن‌ها، منطقه حمل‌ونقل ایران، درگاه‌ها، کاربر و سفارش نمونه و منوها.

مشاهده لاگ (تا رسیدن به `✅ راه‌اندازی کامل شد!`):

```bash
docker compose logs -f web
```

## ۴) بازنشانی و نگهداری

```bash
# ریست کامل (دیتابیس حذف و از نو ساخته می‌شود)
bash bin/reset.sh

# اجرای مجدد نصب/داده نمونه بدون حذف دیتابیس
bash bin/cli.sh provision

# پشتیبان‌گیری دیتابیس (فایل sql در backups/)
bash bin/cli.sh backup

# ورود به شل کانتینر برای عملیات دستی
bash bin/cli.sh shell
```

## ۵) شخصی‌سازی

| می‌خواهید... | کجا |
|---|---|
| تلفن/آدرس/شبکه‌ها | **نمایش → شخصی‌سازی → تماس و شبکه‌های اجتماعی** |
| متن بنر/هیرو و عکس آن | **شخصی‌سازی → صفحه اصلی فروشگاه** |
| لوگو | **شخصی‌سازی → هویت سایت** |
| متن فوتر/کپی‌رایت | شخصی‌سازی → صفحه اصلی (arian_footer_about / arian_copyright) |
| محصول/دسته جدید | پیشخوان → ووکامرس → محصولات |
| هزینه ارسال | ووکامرس → تنظیمات → حمل‌ونقل → منطقه «ایران» |
| درگاه‌ها | ووکامرس → تنظیمات → پرداخت‌ها |
| رنگ‌ها | `wordpress/wp-content/themes/arian-shop/assets/css/main.css` (متغیرهای `--c-*`) |

## ۶) عیب‌یابی سریع

| مشکل | راه‌حل |
|---|---|
| پورت ۸۰۸۰ اشغال است | `WEB_PORT=8090` و `SITE_URL=http://localhost:8090` در `.env` |
| صفحه سایت نصب‌نشده/خطای دیتابیس | `docker compose logs web`؛ سپس `bash bin/reset.sh` |

| رمز مدیر را فراموش کردم | `docker compose exec web php /arian/bin/provision.php --force` سپس از ریست دمو یا تغییر رمز از d.b. |
| کش مرورگر | `Ctrl+F5` |
