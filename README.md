# 🛒 فروشگاه اینترنتی آرین‌شاپ (WordPress + WooCommerce)

یک فروشگاه وردپرسی **کامل و آماده اجرا** با قالب فارسی و راست‌چین اختصاصی، پنل مدیریت ووکامرس،
داده‌های نمونه (۱۶ محصول، تخفیف، کوپن، سفارش و مشتری تستی) و **درگاه پرداخت آزمایشی** برای تست
کامل خرید **به‌صورت آفلاین**.

> ✔ بدون نیاز به هاست یا اینترنت برای اجرا — فقط Docker (برای بار اول، دانلود تصاویر Docker نیاز به اینترنت دارد)

---

## ✨ امکانات

| بخش | توضیح |
|---|---|
| **فروشگاه** | آرشیو محصولات، فیلتر دسته/قیمت، مرتب‌سازی، جستجوی زنده، نشان تخفیف، پیش‌نمایش سریع، علاقه‌مندی |
| **محصول** | گالری تصاویر، انواع محصول (متغیر: رنگ/عدسی)، امتیاز و نظر، محصولات مرتبط، مشخصات و تب‌ها |
| **سبد و تسویه** | مینی‌سبد هدر، سبد کامل، کوپن تخفیف، محاسبه ارسال (رایگان بالای ۵۰۰ هزار تومان)، مشاهده سفارش |
| **پرداخت** | درگاه **آزمایشی شبیه‌ساز** (موفق/ناموفق) + پرداخت در محل + حواله بانکی؛ امکان اتصال درگاه واقعی |
| **حساب کاربری** | ثبت‌نام/ورود، پیشخوان، سفارش‌ها، آدرس‌ها، خروج |
| **پنل مدیریت** | ووکامرس کامل: محصولات، سفارش‌ها، گزارش‌ها، کوپن، حمل‌ونقل، پرداخت‌ها + ویجت خلاصه فروش + ابزار دمو |
| **صفحه اصلی** | هیرو، دسته‌بندی‌ها، پیشنهاد ویژه، تخفیف شگفت‌انگیز با شمارش معکوس، بنر، جدیدترین‌ها، نظر مشتریان، بلاگ، خبرنامه |
| **فنی** | RTL کامل، فونت وزیرمتن (محلی)، اعداد فارسی، امنیت (XML-RPC خاموش، هدرهای امن، توقف تماس با اینترنت در حالت آفلاین)، کاملاً بدون CDN |

## 🚀 اجرا در ۳ دقیقه

**پیش‌نیاز:** [Docker Desktop](https://www.docker.com/products/docker-desktop/) (یا Docker Engine + Docker Compose v2) — فقط برای بار اول اینترنت لازم است.

```bash
# ۱) کپی تنظیمات (اختیاری — پیش‌فرض‌ها آماده‌اند)
cp .env.example .env

# ۲) ساخت و بالا آوردن (نصب وردپرس + ووکامرس + داده نمونه خودکار است)
docker compose up -d --build

# ۳) مشاهده لاگ تا پیام «راه‌اندازی کامل شد!» (دقیقه اول طول می‌کشد)
docker compose logs -f web
```

سپس:

| آدرس | مقدار |
|---|---|
| 🏪 سایت فروشگاه | [http://localhost:8080](http://localhost:8080) |
| 🔐 پیشخوان مدیریت | [http://localhost:8080/wp-admin](http://localhost:8080/wp-admin) |
| 👤 نام کاربری مدیر | `admin` |
| 🔑 رمز عبور مدیر | `Admin@1234` |
| 🧑 مشتری نمونه | `mohammadi` / `Customer@1234` |
| 🎟 کوپن‌های تست | `WELCOME10` (۱۰٪) و `VIP20` (۲۰٪ بالای ۳ میلیون) |

> ⚠️ رمز پیش‌فرض را حتماً از «کاربران → پروفایل» یا `.env` تغییر دهید.

## 🧪 تست کامل خرید (فقط با مرورگر، بدون اینترنت)

1. صفحه اصلی → روی یک محصول با نشان «٪ تخفیف» کلیک کنید.
2. در صفحه محصول: رنگ/گزینه را انتخاب کنید، تعداد را تغییر دهید و **«افزودن به سبد»** را بزنید.
3. مینی‌سبد هدر را باز کنید → **«مشاهده سبد»**.
4. در سبد: کد `WELCOME10` را اعمال کنید و **«ثبت سفارش»** بزنید.
5. در تسویه: فرم را پر کنید (نام، ایمیل، تلفن، آدرس، کدپستی ۱۹۹۸۷۶۵۴۳۲) و روش «پرداخت آنلاین (آزمایشی)» را انتخاب کنید.
6. روی **«ثبت سفارش»** کلیک کنید → وارد **درگاه شبیه‌سازی** می‌شوید:
   - «✓ پرداخت موفق شد» → تأیید سفارش + ایمیل/رسید
   - «✗ پرداخت ناموفق (تست)» → بازگشت به پرداخت برای انتخاب روش دیگر (مثلاً پرداخت در محل)
7. سفارش را از **پیشخوان → ووکامرس → سفارش‌ها** ببینید، وضعیت را «تکمیل‌شده» کنید و از **صفحه پیگیری سفارش** یا حساب «mohammadi» مشاهده کنید.

راهنمای گام‌به‌گام با تصاویر و جزئیات بیشتر: **[docs/راهنمای-اجرا-و-تست.md](docs/راهنمای-اجرا-و-تست.md)**

## 📁 ساختار پروژه

```
├── docker-compose.yml        ← وب + دیتابیس (MariaDB)
├── Dockerfile                ← PHP 8.2 + Apache + افزونه‌های لازم
├── .env.example              ← تنظیمات (پورت، رمزها، آدرس سایت)
├── config/                   ← php.ini و تنظیمات Apache
├── wordpress/                ← وردپرس 7.1 + قالب + افزونه‌ها
│   └── wp-content/
│       ├── themes/arian-shop/        ← قالب اختصاصی RTL
│       ├── plugins/arian-core/        ← امکانات و داده نمونه
│       ├── plugins/arian-pay/         ← درگاه پرداخت آزمایشی
│       ├── plugins/woocommerce/       ← ووکامرس (باندل‌شده)
│       └── mu-plugins/arian-mu.php    ← امنیت + حالت آفلاین
├── bin/                      ← نصب خودکار، ریست، پشتیبان، CLI
└── docs/                     ← آموزش کامل فارسی
```

## 🛠 دستورهای کاربردی

```bash
docker compose logs -f web          # لاگ‌ها
docker compose restart web          # ری‌استارت
docker compose down                 # توقف (داده‌ها می‌مانند)
bash bin/reset.sh                   # ریست کامل به حالت اولیه
bash bin/cli.sh backup              # پشتیبان دیتابیس
bash bin/cli.sh provision           # اجرای مجدد نصب/داده نمونه
bash bin/fetch-woocommerce.sh       # به‌روزرسانی ووکامرس (نیاز به اینترنت)
```

## 🌐 درباره «آفلاین»

- تمام کدها (وردپرس ۷.۱، ووکامرس، قالب، افزونه‌ها، فونت وزیرمتن و تصاویر دمو) داخل همین مخزن قرار دارند.
- در حالت آفلاین، درخواست‌های خروجی سایت بسته می‌شود (بدون نگرانی از تایم‌اوت‌های به‌روزرسانی).
- **تنها** برای بار اول باید تصاویر Docker کش شوند (`docker compose up` خودش انجام می‌دهد). بعد از آن همه‌چیز بی‌نیاز از اینترنت است.
- برای دریافت آخرین ووکامرس (اختیاری) از `bash bin/fetch-woocommerce.sh` استفاده کنید.

## 🔐 امنیت (پیشنهاد)

- تغییر رمز admin از `.env` قبل از اولین اجرا
- در زمان استفاده واقعی: فعال کردن HTTPS، تغییر `SITE_URL`، محدود کردن پورت‌ها
- توسعه واقعی پرداخت: افزودن افزونه درگاه رسمی (زرین‌پال/زیبال) از `پیشخوان → افزونه‌ها`
